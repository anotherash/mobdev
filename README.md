# Лабораторная №1 — Продвинутый калькулятор

Ветка `lab-1`, созданная от `main` репозитория mobdev. Ветка содержит отдельное Flutter-приложение, как разрешено заданием. Стартовый Android-шаблон заменён только в этой ветке. Исходные правила репозитория сохранены в [docs/REPOSITORY_RULES.md](docs/REPOSITORY_RULES.md); упомянутой там ветки `master` в репозитории нет. Для Flutter код находится в `lib/`, тесты — в `test/`, Android-оболочка — в `android/`.

Простое Android-приложение на Flutter/Dart. Без сторонних пакетов для вычислений и управления состоянием.

## Запуск

1. Открыть **эту папку целиком** в VS Code (не только `android`).
2. Запустить виртуальный телефон в Android Studio → Device Manager.
3. В терминале из папки проекта:

```sh
flutter pub get
flutter run
```

Проверки и сборка:

```sh
flutter analyze
flutter test
flutter build apk --debug
```

APK: `build/app/outputs/flutter-apk/app-debug.apk`. Это учебная debug-сборка для установки и демонстрации, не публикация в магазине.

## Где что находится

- `lib/calculator_engine.dart`: чистый Dart; разбор выражений рекурсивным спуском. Сложение/вычитание вызывают уровень умножения/деления, затем уровень числа/скобок. Так обеспечивается приоритет операций.
- `lib/calculator_model.dart`: выражение, память, результат, ошибка и история; сериализация всего состояния.
- `lib/main.dart`: экран Flutter, кнопки и восстановление состояния.
- `test/calculator_test.dart`: вычисления, ошибки, история, память, сериализация.
- `test/widget_test.dart`: кнопки, повторный ввод из истории, смена знака, поворот и восстановление состояния.

## Соответствие заданию

| Требование | Реализация |
|---|---|
| Произвольное выражение | Редактируемое поле, вставка/удаление на позиции курсора, экранные кнопки |
| +, −, ×, ÷, дробные числа, скобки | Отдельный вычислитель, правильный приоритет и порядок слева направо для операций одного уровня |
| = | Вычисляет всё выражение, добавляет успешное вычисление в историю |
| C / ⌫ | Очищает текущий ввод, результат и ошибку / удаляет выделение или символ перед курсором |
| % / ± | Процент числа или скобочного выражения / смена знака числа под курсором |
| История | Последние 10 успешных вычислений, новые сверху; нажатие возвращает выражение для редактирования |
| M+ / M− | Добавляет/вычитает значение текущего выражения из памяти |
| MR / MC | Возвращает память в поле выражения / обнуляет память |
| Состояние при повороте | Выражение, история, память, последний результат, ошибка сохраняются в State; RestorationMixin также восстанавливает их при системном восстановлении |
| Ошибки | Деление на ноль, скобки, соседние операторы, несколько точек, пустой ввод и незавершённое выражение |
| Независимость от UI | Вычислитель не импортирует Flutter и проверяется отдельно |

## Принятые правила

- `%` означает деление на 100: `50% = 0.5`, `200 × 10% = 20`, `200 + 10% = 200.1`. Контекстные банковские проценты не используются.
- Два арифметических оператора подряд считаются ошибкой, даже если второй — минус. Отрицательные числа после операции вводятся в скобках: `2 × (-3)`. Начальное `-3` допустимо. Кнопка ± добавляет скобки автоматически.
- ± меняет знак числа под курсором или непосредственно перед ним; сразу после закрывающих скобок — последнего числа, если оно заканчивается перед ними. Если подходящего числа нет, добавляет минус либо меняет знак скобочного выражения.
- MR заменяет всё текущее выражение числом из памяти. M+/M− вычисляют текущее выражение, не добавляя запись в историю. При ошибке память остаётся прежней.
- При ошибке последний успешный результат остаётся виден вместе с сообщением об ошибке; ошибочные вычисления не добавляются в историю.
- C сохраняет историю и память; для памяти есть отдельная MC.
- Поддерживаются точка и запятая в ручном вводе, а также `*`, `/`, обычный минус. На кнопках — десятичная точка и знаки ×, ÷, −.
- Внутренние значения — double; отображение округляется до 12 значащих цифр. Это обычный учебный калькулятор, не средство точных финансовых расчётов.
- Сохранение при повороте и системном восстановлении реализовано. Постоянное хранение после явного закрытия/force-stop не обещается и в задании не требуется.
- Защита от чрезмерного ввода: до 1000 символов и до 64 уровней скобок; превышение показывает ошибку.

## Сценарий демонстрации

1. `12 + 5 × 3` → 27; `(12 + 5) × 3` → 51.
2. `15.5 × 2` → 31; `50%` → 0.5; `5`, ±, = → −5.
3. Нажать запись истории, изменить выражение, вычислить снова. Сделать больше 10 вычислений — останутся последние 10.
4. `10` → M+, `3` → M−, MR → 7, MC → 0.
5. Проверить `1 ÷ 0`, `(1 + 2`, `2 ++ 3`, `1.2.3`, пустой ввод, `2 +`: приложение показывает ошибку и остаётся работоспособным.
6. Имея историю, память, последний результат и ошибочный ввод, повернуть устройство. Проверить сохранность всех пяти частей состояния.

Для горизонтального экрана калькулятор и история размещаются рядом. При недостатке высоты доступна прокрутка.
