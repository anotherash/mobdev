# Проверка переданного черновика

Прочитаны `PROMPT_FOR_AI.md`, `CONTEXT_FOR_AI.md` из Downloads/lab2_ai_transfer и проект из вложенного ZIP. Исходники из архива взяты за основу; оригинальные файлы передачи сохранены. Предыдущий вариант исходников сохранён отдельно от Git в `Documents/MobileDevLab2/before-handoff-source.zip`.

## Исправления

- Старые плагины контактов/разрешений заменены на один `flutter_contacts 2.5.0`; преобразование данных соответствует его API.
- Исправлен импорт генерируемой локализации; все сообщения вынесены в ARB. Русский интерфейс выбран явно, английский ресурс сохранён.
- Контроллер создаётся один раз; кэш не перечитывается при поиске, сортировке, перестроении или возврате из карточки.
- Разделены отказ, окончательный отказ, пустая книга, пустой поиск и ошибка чтения. Добавлен повторный запрос и переход в настройки.
- На `resumed` проверяется разрешение; при отзыве кэш очищается. Чтение защищено от дублирования, позднего результата после отзыва и уведомления уничтоженного экрана.
- Основной номер выбирается по `isPrimary`. Поддерживаются отсутствующие поля, адреса, заметки, сайты и даты.
- Открытая карточка использует актуальный кэш, скрывает данные при отзыве доступа и сообщает об исчезновении контакта.
- Поиск и сортировка сохраняются при повороте; подключён restoration. Панель сортировки переносится при нехватке ширины, содержимое доступно при маленькой высоте/клавиатуре.
- Android applicationId/namespace: `ru.student.device_contacts`, разрешение только на чтение адресной книги. Название приложения — ресурс Android.
- Вместо поверхностных тестов добавлены 23 проверки реального поведения с подменяемым репозиторием.

## Проверки

`flutter pub get`, `flutter gen-l10n`, `flutter analyze`, `flutter test` и `flutter run -d emulator-5554 --no-resident` выполнены успешно. Android APK собран и установлен. Анализатор: без замечаний; тесты: 23 успешных.

На Android-эмуляторе API 37 проверены первый отказ, повторный отказ с переходом к настройкам, выдача доступа в настройках, список из шести демонстрационных контактов, карточка с основным и дополнительным номером/email, поиск и обратная сортировка, сохранение фильтра и сортировки при повороте, скрытие контактов после отзыва доступа и последующего отказа.

Пустая книга, ошибка чтения, отсутствие лишних чтений и отзыв доступа во время незавершённого чтения покрыты автоматическими тестами. Реальный физический телефон и iOS не проверялись; iOS не входит в выбранную цель. Перед защитой полезно пройти сценарий из README на том устройстве, которое будешь показывать.

Контакты, изменённые в другом приложении при неизменном разрешении, перечитываются кнопкой «Обновить». Автоматическая подписка на изменения книги не добавлялась: задание требует избегать лишних чтений, а не постоянной синхронизации.
